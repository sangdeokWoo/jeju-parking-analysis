## 3단계 — 수요-공급 공백 (완료, 방법론 데모)

- **공급**: 위 주차면 수 (행정동별 집계)
- **수요**: 읍면동 유동인구 (`web/data/demand_emd.csv`)

## 입지 추천 (신설·증설 우선순위)

- 공백 분석 상위 행정동을 **신설**(공영주차장 0곳) / **증설**(주차면당 유동인구 높음)으로 분류.
- 후보 지점 = 행정동 ∩ **주거지역(OSM landuse=residential)** 격자 중 기존 공영주차장에서 가장 먼 곳.
  - 주거지역 제한으로 **산·오름 오판을 방지**(2022년이 금오름·붉은오름에 추천한 실수의 교정).
- 스크립트 `web/scripts/recommend_sites.py`, 결과 `web/data/recommend_sites.csv`.

## 한계

- **수요 데이터 시점(2017~2020)이 공급(2026)과 다름.** 방법론 데모용. 오픈API로 최신화 필요.

- 주차 수요는 유동인구 외 체류시간·차량분담률·회전율의 영향도 받음(미반영).
